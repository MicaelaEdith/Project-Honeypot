Project Honeypot is a top-down action game where you control a tank to protect the last queen bee on Earth. Deploy explosive honey traps, dodge enemy ships, and save humanity.
A story about the desolation of a dying world and the almost absurd determination to keep fighting to save it.

Development:

Engine: Unity
3D Modeling: Blender


Bachelor's Degree in Video Game Development and Production — Universidad de la Ciudad.
Midterm Project for Programming II — October 2026.
